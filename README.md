# Quantum Machine Learning Foundations 🚀

A hands-on repository documenting my journey bridging Classical AI/Data Science with Quantum Computing.

## 📌 Focus Areas
- **Quantum Foundations:** Superposition, Entanglement, Unitary Transformations, Measurement.
- **Tools & Frameworks:** PennyLane, IBM Quantum Composer, Python, Matplotlib.
- **Goal:** Exploring Parameterized Quantum Circuits (PQCs) and Quantum Machine Learning (QML).

## 📂 Notebook Progression

| # | Topic | Key Concepts | Framework |
|---|---|---|---|
| 01 | Single Qubit Gates | Pauli-X, Hadamard, Bloch Sphere rotations | PennyLane / IBM |
| 02 | Entanglement & Bell State | CNOT, Superposition, Correlated measurement | PennyLane |
| 03 | Parameterized Circuits | Trainable rotation gates ($RX, RY$), Gradient Descent | PennyLane |
